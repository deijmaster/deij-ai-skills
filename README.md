# deij-ai-skills

Small, practical skills for AI agents (OpenClaw and other AgentSkills-compatible tools). Each folder is one skill with a single `SKILL.md`.

## Skills

| Skill | What it does |
| --- | --- |
| [ss](ss/SKILL.md) | Type `/ss` and the agent grabs your latest screenshot and looks at it. No more drag and drop. |

## Install

Copy a skill folder into your agent's skills directory. For OpenClaw:

```
cp -r ss ~/.openclaw/workspace/skills/
```

Start a new session so the skill list refreshes.

## Notes

- `ss` is tested on macOS. The Windows and Linux paths are untested; fixes welcome.
